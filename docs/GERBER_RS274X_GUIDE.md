# Etch EDA: Manufacturing Formats Guide (Gerber RS-274X, Excellon, IPC-D-356)

## 1. RS-274X Extended Gerber Specification

RS-274X (Extended Gerber) is the universal vector format used by laser photoplotters to create photographic film and direct-imaging masks for printed circuit board fabrication.

### Header Format
Etch generates standard RS-274X headers with format 4.6 metric coordinates:

```gerber
G04 Layer: COPPER_F.Cu*
G04 Generated by Etch EDA - High Precision PCB Engine*
%FSLAX46Y46*%
%MOMM*%
%LPD*%
G01*
G75*
```

* `%FSLAX46Y46*%`: Format Specification.
  * `L`: Leading zero omission.
  * `A`: Absolute coordinate addressing.
  * `X46Y46`: 4 integer digits, 6 decimal digits. 1 mm corresponds to 1,000,000 internal units (exact nanometer match).
* `%MOMM*%`: Mode Millimeters.
* `%LPD*%`: Layer Polarity Dark.
* `G01*`: Linear interpolation mode.
* `G75*`: Multi-quadrant circular arc interpolation.

### Aperture Definitions
Apertures define the shape and dimensions of the photoplotter beam:

* **Circle (`C`)**: Used for trace routing and circular pads:
  ```gerber
  %ADD10C,0.200000*%
  ```
* **Rectangle (`R`)**: Used for SMD chip pads:
  ```gerber
  %ADD11R,1.000000X1.350000*%
  ```
* **Obround (`O`)**: Used for oval connector and IC pads:
  ```gerber
  %ADD12O,1.600000X1.000000*%
  ```

### Drawing Operations
* `D10*`: Selects aperture code 10.
* `X1000000Y2000000D02*`: Moves to coordinate $(1.0\text{ mm}, 2.0\text{ mm})$ with exposure shutter closed.
* `X1500000Y2000000D01*`: Draws a continuous line segment to $(1.5\text{ mm}, 2.0\text{ mm})$ with shutter open.
* `X1000000Y2000000D03*`: Flashes the selected pad aperture at the specified coordinate.
* `M02*`: End of file marker.

## 2. Excellon NC Drill File Specification (Format 2)

Excellon numeric control (NC) files drive automated CNC drilling machines that drill via holes, component pin holes, and board mounting cutouts.

```excellon
M48
; DRILL file {Etch EDA} date 2026-11-09
METRIC,TZ
T01C0.300
T02C0.800
T03C3.200
%
T01
X10.500Y20.250
X15.000Y22.500
T02
X5.000Y10.000
M30
```

* `M48`: Start of header.
* `METRIC,TZ`: Coordinates are in millimeters with trailing zero suppression.
* `T01C0.300`: Tool 1 defined with 0.300 mm diameter (standard via drill).
* `T02C0.800`: Tool 2 defined with 0.800 mm diameter (THT pin drill).
* `%`: Rewind / End of header.
* `T01`: Selects tool 1.
* `X...Y...`: Canned drill strike coordinates.
* `M30`: End of program.

## 3. IPC-D-356 Bare-Board Electrical Test Netlist

IPC-D-356 files contain exact coordinate records for automated flying-probe continuity testers to verify that 100% of physical nets match the schematic netlist:

```ipc
C  IPC-D-356 Electrical Test File generated by Etch EDA
P  JOB   stm32_sensor_hub
P  UNITS CUST 0
327 GND            U1-EP          M A01 X0037500 Y0025000
317 GND            J1-SH1         M A01 X0006000 Y0025500
999
```

* `327`: Surface mount (SMD) test point record.
* `317`: Plated through-hole (THT) test point record.
* `GND`: Electrical net designator.
* `U1-EP`: Component reference designator and pin number.
* `A01`: Primary top copper access layer.
* `X... Y...`: Exact probe target coordinates in tenths of microns.
* `999`: End of file terminator.

## 4. Pick-and-Place Centroid (CPL) Specification

Centroid CSV files direct automated SMT pick-and-place feeders:

```csv
Designator,Val,Package,Mid X,Mid Y,Rotation,Layer
U1,"STM32F401CCU6","QFN-32",37.500,25.000,0.0,Top
C1,"100nF","0402",30.000,25.000,0.0,Top
J1,"TYPE-C-16P","USB-C",6.000,25.000,90.0,Top
```

Provides geometric center of mass coordinates (Mid X, Mid Y in mm), rotation in degrees, and board placement side (Top or Bottom).
